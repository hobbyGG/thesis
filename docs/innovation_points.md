# 当前论文的创新点定位

本文档只总结当前代码真正实现、且可以通过实验验证的创新点。创新点按照“核心算法—融合方法—系统实现”分层，避免把成熟工具或硬件连接过程写成算法创新。

## 1. 核心创新：免离线方向转换因子的加速度辅助 Kalman 相位解缠

### 1.1 前序方法的使用限制

当前最直接的前序是 *Acceleration-aided Kalman filtering for joint phase denoising and unwrapping*。该方法把相位和相位变化率作为状态，并利用加速度预测下一时刻相位，从而在预测相位附近选择正确的 \(2\pi\) 分支。它能够同时完成相位降噪和相位解缠，但实际使用需要先进行一段离线阶段：用同步采集的雷达相位和加速度位移估计雷达视线位移到结构位移的方向转换因子，然后再进入正式在线处理。

这个离线阶段带来两个实际限制：

1. 安装后需要先激励结构并完成一轮专门的同步标定；
2. 转换因子绑定于当前安装方向和测点，换安装位置、换观测目标或换角度后需要重新估计。

本文不把加速度辅助 Kalman 重新包装成一个完全不同的滤波器，而是消除它对离线方向转换因子估计的依赖。

### 1.2 当前方法的在线几何替代

当前算法在每个输入记录内直接从 Range-Angle 结果得到目标的 AoA，并按目标计算方向系数：

\[
\beta_i=\frac{1}{|\cos\theta_i|},
\]

其中 \(\theta_i\) 是第 \(i\) 个目标的 AoA。`algorithm/frontend.py` 中的局部 MUSIC/最小二乘 AoA 细化产生 \(\theta_i\)，随后形成 `measured_beta`。该值在当前记录内固定，用于该记录的结构相位观测模型；它不是预先从一段结构运动数据拟合得到的文件参数。

对共享结构相位状态 \(\Theta_k\)，代码使用的目标级观测关系是：

\[
\phi_{i,k}^{\mathrm{pred}}=\frac{\Theta_{k|k-1}}{\beta_i}+b_i,
\]

其中 \(\phi_{i,k}\) 是 wrapped radar phase，\(b_i\) 是冷启动阶段估计的目标相位偏置。以预测相位为中心进行分支修正后，得到连续的目标视线相位 \(\tilde\phi_{i,k}\)，再统一到结构主相位：

\[
y_{i,k}=\beta_i(\tilde\phi_{i,k}-b_i).
\]

因此，当前完整链路是：

```text
当前记录的 ADC
  → Range FFT / 角度处理
  → 局部 AoA θ_i
  → 在线计算 β_i
  → 加速度原生时间区间预积分
  → acceleration-aided Kalman 预测
  → 在预测相位附近修正 wrapped phase 的 2π 分支
  → 统一到结构主相位
```

论文中建议使用以下表述：

> 提出一种基于在线 AoA 几何观测的免离线方向转换因子 acceleration-aided Kalman 相位解缠方法，实现雷达与加速度传感器的采集后直接处理。

“免离线方向转换因子”是准确的边界；不能写成“完全不需要标定”。阵列几何、载频和波长、安装方向、角度符号约定以及采集时间轴仍然是算法配置条件。当前实现的 AoA/beta 是**记录级在线计算、记录内冻结**，不是每个采样点都重新追踪姿态。

### 1.3 该创新必须如何验证

至少需要做以下对照：

- 前序方法的“离线转换因子 + acceleration-aided Kalman”与当前“在线 AoA-derived beta + acceleration-aided Kalman”；
- 人工固定 \(\beta=1\) 与在线 \(\beta_i\)；
- 正确角度、角度偏差和不同安装方向；
- 不同目标角度以及换目标后是否需要重新离线标定；
- 相位连续性、错误 \(2\pi\) 分支次数、位移 RMSE 和启动时间。

## 2. 多目标、多方向的共同结构相位估计

### 2.1 多目标不是目标切换

`algorithm/selection.py` 从距离—角度图中保留多个候选目标；`algorithm/frontend.py` 为每个候选目标保留自己的距离、AoA、复数慢时间序列和 wrapped phase。Kalman 更新时，当前时刻所有可用目标都作为同一个结构状态的观测，而不是只选一个 best target 或在目标之间切换。

设当前可用目标集合为 \(\mathcal A_k\)，每个目标统一后的结构相位观测为 \(y_{i,k}\)，观测方差为 \(R_{i,k}\)，代码先做逆方差融合：

\[
z_k=\frac{\sum_{i\in\mathcal A_k}R_{i,k}^{-1}y_{i,k}}
                 {\sum_{i\in\mathcal A_k}R_{i,k}^{-1}},\qquad
R_k=\left(\sum_{i\in\mathcal A_k}R_{i,k}^{-1}\right)^{-1}.
\]

随后由一个共享的二阶结构相位状态更新：

\[
\mathbf x_k=[\Theta_k,\dot\Theta_k]^T.
\]

每个目标仍保留自己的 innovation，代码根据后验残差和状态协方差更新目标级 \(R_{i,k}\)。这样，暂时稳定的目标具有更高权重，噪声较大的目标不会等权拉动共同结构状态。

### 2.2 多方向是投影统一，不是完整三维反演

不同环境散射目标对应不同 AoA，因此其 LOS 相位对同一结构运动的投影不同。当前算法通过 \(\beta_i\) 把这些多方向投影统一到一个结构主相位，再输出主方向位移：

\[
\hat q_k=\frac{\hat\Theta_k\lambda}{4\pi}.
\]

这项贡献应写成“多方向 LOS 投影的共同状态统一”。当前代码没有求解结构横向分量、转角或完整三维姿态，也没有多雷达空间交会，因此不能宣称 3D 位移重建或姿态标定。

## 3. 多传感器的原生时间轴融合

雷达和 ADXL355 在采集阶段没有共用 ADC 时钟。当前算法不把 ADXL 简单重采样到雷达序列后再积分，而是在每两个相邻雷达时间点之间使用 ADXL 原生时间戳区间预积分，得到：

\[
\Delta v_k=\int_{t_k}^{t_{k+1}}a(t)\,dt,
\qquad
\Delta q_k=\int_{t_k}^{t_{k+1}}v(t)\,dt.
\]

`algorithm/acceleration.py` 用梯形速度积分和分段二次位移积分得到 \(\Delta v_k,\Delta q_k\)。Kalman 预测阶段把它们转换为相位增量：

\[
\mathbf x_{k+1|k}
=A_k\mathbf x_{k|k}
+\frac{4\pi}{\lambda}
\begin{bmatrix}\Delta q_k\\\Delta v_k\end{bmatrix}.
\]

因此多传感器融合的分工是清楚的：

- 雷达：提供目标级 wrapped phase、AoA 和可用性；
- ADXL355：提供相邻雷达时刻之间的速度/位移预测，帮助判断正确的相位分支；
- 共享 Kalman：利用多目标雷达观测修正加速度预测，并输出结构相位和位移。

这不同于“雷达低频位移 + 加速度高频分量”的普通互补 FIR。当前重点是利用加速度预测解缠，再用多目标雷达观测共同更新结构状态。

## 4. 系统和工程化贡献

系统贡献服务于可重复实验和快速部署，不冒充新的物理公式。

### 4.1 统一输入契约

三个目录边界保持固定：

```text
capture_program/
  实测 IWR1843/DCA1000/ADXL355 采集
  → capture_root

measured_bridge_simulation/
  实测激光位移驱动的半实测数据生成
  → 同样的 capture_root

algorithm/
  读取 capture_root
  → 位移结果
```

真实采集和半实测场景都输出 `adc_cube`、ADXL 时间/加速度和同步时间轴，算法不读取 PCAP、LVDS、串口或 GPIO。这样可以把采集问题、半实测验证和论文算法分开，保证同一算法在两种数据源上运行。

### 4.2 采集后直接运行

IWR1843 的 ADC 经 DCA1000 形成原始雷达输入包，ADXL355 保留原生采样时间；树莓派只负责采集、时间记录、解码和导出统一包。算法端从统一包恢复距离—角度目标、在线 AoA/beta、原生时间预积分和 Kalman 结果。

与需要保存每个安装点离线转换因子的前序流程相比，当前流程少了一份现场专用标定数据和一个独立离线阶段。论文中可以把这一点称为“采集后直接运行”和“跨安装点复用的几何计算流程”，但应通过安装方向、目标角度和换场景实验验证其实际收益。

## 5. 不应作为创新点单独宣称的内容

- Range FFT、角度 DBF、局部 MUSIC、最小二乘 AoA、普通 \(2\pi\) 分支修正和标准二阶 Kalman 都是成熟组件；
- \(\beta_i=1/|\cos\theta_i|\) 这个几何公式本身不是新公式；
- Raspberry Pi、DCA1000、UDP、PCAP 和统一目录属于采集/实验工程实现；
- 当前没有在线目标重关联、目标遮挡管理、Doppler 解缠、multi-chirp 自适应解缠、周期滤波、学习型去噪或多雷达三维反演；
- 半实测桥梁场景中的激光位移真值用于评价，不参与目标选择、AoA、beta 或 Kalman 更新。

## 6. 推荐的论文贡献表述

建议把贡献组织为以下三条，而不是把每个代码函数都列成“创新”：

1. **免离线方向转换因子的加速度辅助 Kalman 相位解缠**：利用当前记录的 AoA 在线生成目标方向系数，取消前序方法中正式监测前的专门转换因子估计阶段。
2. **多目标、多方向的共同结构相位估计**：把不同环境目标作为同一结构状态的投影观测，用目标级几何统一、逆方差融合和自适应观测方差提升相位解缠和位移估计的连续性。
3. **原生时间轴多传感器融合与可复现实验系统**：用 ADXL355 原生时间区间预积分参与 Kalman 预测，并通过真实采集/半实测场景共用 capture package 实现采集后直接运行和可重复验证。

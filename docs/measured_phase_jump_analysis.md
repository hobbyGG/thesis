# 实测位移在 frame 与 chirp 时间尺度上的相位跳变

## 数据和计算口径

- 数据文件：`datafile/20250320test12.tdms`
- 通道：`卡3激光位移/3-4`
- 事件窗口：15.33–19.33 s
- TDMS 原始采样率：约 3000.075 Hz
- 雷达载频：77 GHz
- 波长：

  $$
  \lambda=\frac{c}{77\ \mathrm{GHz}}\approx3.8934\ \mathrm{mm}
  $$

相位增量按照当前模型的最保守情况 `beta=1` 计算：

$$
|\Delta\phi|
=\frac{4\pi}{\lambda}|\Delta q|
$$

实际目标的 `beta=1/|cos(theta)|` 大于或等于 1，因此实际 LoS 相位增量只会更小。

带限信号采用当前半实测代码的处理思路：换算为米、去除前 0.2 s 均值、保留 0.2–40 Hz。为了分析 127.14 us 和 254.28 us 间隔，带限操作在 TDMS 原始采样率上完成，再按精确时间间隔插值；直接使用当前 1 kHz 输出无法分辨 chirp 级时间间隔。

## 相邻采样的绝对相位增量

| 时间间隔 | 信号 | 位移增量最小 / 中位数 / 最大 (mm) | 相位增量最小 / 中位数 / 最大 (rad) | 是否超过 π |
| --- | --- | ---: | ---: | --- |
| 10 ms，frame | 0.2–40 Hz 带限 | 0.000040 / 0.009813 / 0.132990 | 0.000128 / 0.031671 / 0.429239 | 否 |
| 10 ms，frame | 去基线原始信号 | 0.051942 / 0.297364 / 0.560850 | 0.167649 / 0.959773 / 1.810199 | 否 |
| 127.14 us，物理 chirp 间隔 | 0.2–40 Hz 带限 | 0.000000004 / 0.000145 / 0.001791 | 0.000000012 / 0.000469 / 0.005780 | 否 |
| 127.14 us，物理 chirp 间隔 | 去基线原始信号 | 0 / 0.006574 / 0.021286 | 0 / 0.021217 / 0.068703 | 否 |
| 254.28 us，完整 TDM loop 间隔 | 0.2–40 Hz 带限 | 0.0000001 / 0.000291 / 0.003581 | 0.0000004 / 0.000938 / 0.011558 | 否 |
| 254.28 us，完整 TDM loop 间隔 | 去基线原始信号 | 0 / 0.013115 / 0.042572 | 0 / 0.042331 / 0.137406 | 否 |

当前雷达配置中，一个物理 chirp 的近似周期为：

$$
70\ \mu s+57.14\ \mu s=127.14\ \mu s
$$

一个完整 TDM loop 包含 TX0 和 TX2 两个物理 chirp，因此同一虚拟阵元再次出现的间隔约为：

$$
2\times127.14\ \mu s=254.28\ \mu s
$$

对于没有 TX 间相位标定的直接相位跟踪，254.28 us 是更适合比较同一虚拟阵元的时间间隔。

## 结论

对于这段实测桥梁位移：

1. 在当前 100 Hz frame 间隔下，带限运动造成的最大相邻相位跳变约为 `0.429 rad`，即使看去基线但未带限的原始信号，最大约为 `1.810 rad`，都小于 `π`。因此，**该事件的运动本身不会在相邻 frame 之间直接造成相位跳变超过 π**。
2. 在完整 TDM loop 间隔下，带限信号最大相位跳变约为 `0.0116 rad`，原始信号最大约为 `0.1374 rad`，chirp/loop 级别具有很大的相位连续性余量。
3. 相邻采样不跨 `π` 不代表整段信号没有 phase wrapping。带限位移在整个事件内的变化范围约为 2.11 mm，对应总相位变化约 6.80 rad，因此长时间序列仍可能跨过包裹相位边界，需要持续相位解包裹或预测辅助解包裹。
4. 以上结论只描述真实结构运动引起的相位变化。真实雷达还会叠加 SNR、相位噪声、目标混叠、TDM TX/RX 固定相位差和距离迁移等误差；TDMS 激光数据无法评价这些雷达误差。

因此，chirp/loop 级直接位移测量在当前实测运动上确实更不容易出现相位缠绕，但是否比 frame 级更精确，还取决于单 chirp SNR、TDM 相位标定和 chirp 级时间同步是否处理好。

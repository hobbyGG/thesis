# 面向磁浮轨道梁的模块迁移矩阵（工作稿）

这份矩阵把阶段性方法库中的模块放回你的实际测量链路。它用于安排全文核验和论文方案讨论，不把已有算子直接写成原创贡献。

## 适合写成“已有模块”的部分

- Range FFT、慢时间 Doppler、CFAR、波束形成和 MUSIC 属于雷达或阵列信号处理常用模块。
- atan2、DACM、相位展开、圆/椭圆拟合、EMD/VMD、STFT、KF/EKF/FIR 等在不同雷达体制和通用信号处理中均已有先例。
- LOS 投影、加速度积分、模态识别和协方差加权也不应单独声称为首创。

## 可能形成论文核心胶水的部分

1. **共同结构位移状态**：把多个 range/angle 散射点的雷达 LOS 观测和 ADXL355 加速度统一写成同一个结构位移潜变量，而不是简单平均多个位移序列。
2. **加速度辅助的相位解缠与失锁恢复**：先用 ADXL355 的短时动态预测约束雷达相位增量，再用雷达绝对相位把积分漂移拉回；遮挡或低质量时切换到预测状态。
3. **目标级质量协方差**：把 IQ 圆拟合残差、相位连续性、SNR、角度稳定性和雷达–加速度创新量转成观测协方差，驱动目标选择、融合权重和失锁切换。
4. **模态约束的融合后处理**：利用已知的前六阶频带和结构模态先验，区分真实梁响应、局部散射点变化和雷达伪跳变。

这四个位置中，前两个最适合构成主创新的候选；质量协方差和模态约束可以作为辅助创新。最终能否声称“新”，必须在全文核验后检查是否已有论文把同样的观测方程、切换规则和质量变量组合起来。

# Phase 1 Algorithm Chain Review

本文档用于对照理论方法链条与当前代码实现。结论是：当前已实现完整合成仿真链路，但真实 IWR1843 ADC 文件解析、真实天线幅相标定、实测桥梁多径验证仍未实现，属于后续实测阶段。

默认 `run_validation` 只输出论文主实验方法和论文主场景。主方法集为：`oracle`, `range_bin_itoh`, `ma2026_reproduction`, `selected_aoa_fixed_kappa`, `proposed_full_pipeline_kappa_confidence`。主场景集为：`literature_maglev_modal_response`, `strong_wrapping`, `same_range_far_angles`, `aoa_error_bootstrap`, `target_snr_drop`, `vehicle_event_nonstationary`。其余早期版本、消融方法和附录/诊断场景仍保留，可通过 `run_validation --method-set all`, `run_validation --scenario-set all` 或 extended validation 显式运行，但不进入默认主结果表。其中 `itoh_ls` 仅作为理想 target-level 单目标诊断参考保留，不再作为传统毫米波雷达基本 baseline；`range_bin_only_mixed_phase` 仅作为同 range-bin 混合相位机制消融保留。

## 边界结论

已实现：完整合成仿真链路，包括 100 Hz/200 Hz 慢时间 frame/Kalman 率与 6 MHz ADC 快时间显式分离的 synthetic ADC cube、Range FFT、Angle FFT / DBF、Range-Angle Map、2D peak detection、同 rangeBin 近角度合并、同 rangeBin 远角度分离、滑动窗口稳定性、结构频带一致性筛选、selected target Kalman 接入、prediction-aided phase correction、calibrated Q、当前版本 confidence-aware target-wise R、online kappa bootstrap 和相对位移输出；同时新增了文献主频驱动磁浮轨道梁响应场景，用于在没有可靠实测 radar ADC 的情况下，用文献主频和车辆事件包络构造可解释的桥梁动力响应仿真。本地 TDMS 半实测桥梁场景保留为可选诊断，不作为默认正式验证。

主方法边界：论文算法优化方向表述为 calibrated `Q` + SNR-informed initial `R_i,0` + posterior-residual / quality-gated confidence-aware target-wise online `R_i,k^{eff}`。其中 `Q` 是结构主相位动力学模型的全局标定参数，用于保持加速度驱动预测的统计尺度；`R_i,k^{eff}` 是目标观测通道的在线权重，用于响应 SNR、遮挡、后验残差、target quality 和转换系数误差变化。Ma 2026 中固定 `R=1` 后遍历 `Q=10^j` 的做法说明 Kalman 效果主要受 `Q/R` 相对权重影响，且该选择发生在离线或初始标定段，不构成在线 adaptive Q。Akhlaghi 等人的 adaptive noise covariance 工作进一步支撑本文的关键分工：prediction innovation 不能直接归因于 measurement noise，强结构响应下的大 innovation 更可能包含过程预测不确定性；measurement noise `R` 更应由 posterior residual 和观测质量指标约束更新。Mehra 和 Li 等工作分别支撑 covariance matching 与多观测通道 measurement-noise covariance estimation。本文不是照搬上述公式，而是把这些统计原则改造为多 target 结构主相位 Kalman 中的 target-wise `R_i,k`、quality gate 和 `kappa` 置信度传播机制，用于解决 AoA cold start、相位分支校正和多目标权重稳定问题；adaptive `Q` 或 sliding-window `q` 只作为后续扩展，不纳入当前主方法结论。

未实现：真实 IWR1843 ADC 文件解析、真实天线幅相标定、真实 TDM-MIMO 相位补偿、实测桥梁环境多径建模、现场安装姿态标定、真实毫米波雷达 ADC 与 TDMS 同步采集验证和实测长期稳定性验证。

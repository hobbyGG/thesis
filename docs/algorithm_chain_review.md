# Phase 1 Algorithm Chain Review

本文档用于对照理论方法链条与当前代码实现。结论是：当前已实现完整合成仿真链路，但真实 IWR1843 ADC 文件解析、真实天线幅相标定、实测桥梁多径验证仍未实现，属于后续实测阶段。

## 边界结论

已实现：完整合成仿真链路，包括 100 Hz 慢时间 frame/Kalman 率与 6 MHz ADC 快时间显式分离的 synthetic ADC cube、Range FFT、Angle FFT / DBF、Range-Angle Map、2D peak detection、同 rangeBin 近角度合并、同 rangeBin 远角度分离、滑动窗口稳定性、结构频带一致性筛选、selected target Kalman 接入、prediction-aided phase correction、calibrated Q、confidence-aware target-wise R、online kappa bootstrap 和相对位移输出；同时新增了实测激光位移驱动的半实测桥梁场景，用于在真实非平稳响应波形下生成合成雷达相位，并由激光反演加速度加噪声提供动力学输入以比较方法性能。

主方法边界：论文算法优化方向表述为 calibrated `Q` + SNR-informed initial `R_i,0` + confidence-aware target-wise online `R_i,k^{eff}`。其中 `Q` 是结构主相位动力学模型的全局标定参数，用于保持加速度驱动预测的统计尺度；`R_i,k^{eff}` 是目标观测通道的在线权重，用于响应 SNR、遮挡、相位残差和转换系数误差变化。Ma 2026 中固定 `R=1` 后遍历 `Q=10^j` 的做法说明 Kalman 效果主要受 `Q/R` 相对权重影响，且该选择发生在离线或初始标定段，不构成在线 adaptive Q。桥梁 acceleration+strain displacement estimation 类工作也支持固定 `Q`、在线估计测量噪声 `R` 的分工：过程噪声可由传感器和结构模型给定，而观测噪声更容易随目标质量和外部条件变化。Mehra、Mohamed-Schwarz、Li 的 INS-GNSS 及 Sage-Husa radar tracking 等自适应滤波文献支撑 innovation/covariance matching、measurement noise covariance estimation、多观测通道 target-wise `R` 以及 clipping/鲁棒约束。本文在该思路下把 AoA cold start 的转换系数方差传播到有效观测噪声中，作为支撑在线自举的实现机制；posterior-residual adaptive `R` 保留为消融候选。adaptive `Q` 或 sliding-window `q` 只作为后续扩展，不纳入当前主方法结论。

未实现：真实 IWR1843 ADC 文件解析、真实天线幅相标定、真实 TDM-MIMO 相位补偿、实测桥梁环境多径建模、现场安装姿态标定、真实毫米波雷达 ADC 与 TDMS 同步采集验证和实测长期稳定性验证。

# 近三年国际文献检索清单（2023-09-22—2026-09-22）

## 统计口径

研究对象按“高刚度磁浮轨道梁/导轨结构的非接触微位移与振动测量”理解。检索分为三层：

1. 磁浮轨道梁、导轨和车辆—轨道梁动力响应；
2. 普通铁路、桥梁和高刚度结构的毫米波雷达位移/振动测量；
3. FMCW/mmWave 雷达的相位解缠、微位移估计和雷达—加速度计融合。

不纳入中文期刊、国内会议和预印本主文献。国际期刊中的中国作者论文仍保留，因为筛选依据是发表载体和方法质量，而不是作者国籍。SCI/SCIE 状态按期刊通常的 Web of Science 收录情况判断；新刊和会议论文需要在正式写作前用学校 JCR/WoS 清单复核。

OpenAlex 首轮全文召回的查询总量为：磁浮对象层 365 条、结构雷达应用层约 2,411 条、通用雷达方法层约 1,443 条。全文命中包含大量重复和无关内容。按题名/摘要筛选、DOI 去重后，当前保留约 43 篇高相关候选，其中约 35 篇为 SCI/SCIE 期刊论文，约 25 篇属于优先阅读的高水平期刊。

## 初步研究空白

近三年高水平文献形成了两条相对分离的路线：磁浮论文重点研究车—轨道梁耦合动力学、导轨刚度、轨道不平顺和现场加速度；毫米波雷达论文重点研究桥梁或一般结构的非接触位移、相位解缠和多传感器融合。直接把 60/77 GHz FMCW 雷达用于高刚度磁浮轨道梁小位移实测的工作仍然很少。

因此，当前课题可以明确定位为：将桥梁场景中已经验证的 FMCW 雷达相位位移方法迁移到高刚度磁浮轨道梁，并针对小幅、高频、低位移响应处理雷达相位、chirp/frame 时间尺度、视线方向投影和加速度辅助状态估计。

## 一、我的当前研究背景

研究对象是高刚度磁浮轨道梁/导轨结构的非接触微位移和振动测量，使用毫米波 FMCW 雷达与加速度传感器。

当前代码实际采用的链路是：

统一 capture package
→ 雷达 ADC/IQ
→ Range FFT
→ Angle DBF，形成 range-angle 数据
→ 记录级距离—角度候选目标检测
→ 局部 MUSIC/ML 估计连续 AoA
→ 按目标角度计算 beta = 1 / abs(cos(theta))
→ 在 ADXL355 原生时间轴上进行区间速度/位移预积分
→ acceleration-aided structural-phase Kalman
→ 多个目标作为同一结构主相位的观测进行加权更新
→ 输出结构位移 q_hat

当前核心方法是：

1. 基于在线 AoA 几何观测生成目标方向投影系数，避免前序方法必须先离线估计方向转换因子；
2. 利用加速度预测相位状态并辅助 2π 分支修正，实现相位解缠和滤波；
3. 将多个雷达目标的 LOS 相位统一到公共结构主相位后共同更新 Kalman 状态；
4. 利用雷达时间轴和 ADXL355 原生时间轴之间的区间预积分完成异步融合。

当前代码没有使用 PINN、神经网络、深度学习、结构 PDE 残差训练、完整三维位姿反演、在线目标 tracker 或通用工程服务框架。请不要把这些内容臆造为当前方法的一部分。

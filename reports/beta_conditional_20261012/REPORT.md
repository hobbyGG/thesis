# Conditional beta correction

本次主算法保留 AoA β 为默认尺度，只在三个条件同时满足时启用 ADXL 匹配 β：

- 选中目标的最低距离 FFT SNR ≥ 15 dB；
- ADXL 因果匹配位移的 0.10 s 滚动 RMS ≥ 5 μm；
- 至少两个目标的 AoA–ADXL β 相对偏差 ≥ 1%。

SNR 使用前 256 个保存 chirp 观测的 Hamming 距离 FFT，在 DBF 前估计，之后作为质量门控量使用；因此没有用后续振动样本或仿真 truth 决策。

## 阈值证据

压力数据的选中目标最低 SNR 为：20 dB 注入组 19.38 dB，15 dB 注入组 14.38 dB，10 dB 注入组 9.38 dB。15 dB 门槛会保护最低目标已经跌到约 14.4 dB 的边界；10 dB 组不会进入 ADXL 修正。响应事件中的匹配位移 RMS 中位数约为 34.9 μm，5 μm 门槛留有足够激励余量。

1% β 偏差和“至少两个目标”联合条件在名义 AoA 场景不触发；在 +2° 和 +3° 的 AoA 系统偏差场景中触发。+1° 场景也会触发，作为较早的校正点。

## 三次响应

- 事件 1 RMSE：3.728 μm
- 事件 2 RMSE：3.470 μm
- 事件 3 RMSE：3.694 μm
- 三个事件合并 RMSE：3.633 μm
- 全记录 RMSE：3.641 μm

当前名义三响应没有满足 β 修正条件，触发样本为 0，校正目标样本为 0；因此结果与 AoA β 基线一致，同时保留了在 AoA 偏差且 SNR、ADXL 激励可靠时的修正路径。

# 无关文献暂存说明

本目录存放当前 thesis 主线暂不建议引用的 PDF。这里的“无关”不是否定论文质量，而是指它们不直接服务于当前问题：

- 倒挂式毫米波 FMCW 雷达结构位移测量；
- 静止参考 target 在线选择；
- IQ/相位处理、相位解缠、转换因子估计；
- 多 target 位移融合与结构监测实验对照。

主要被移入本目录的类型包括 PINN/神经场求解、6G/ISAC/RadCom/车载通信感知、人体生命体征、目标分类、安防检测、交通/车辆应用等。逐篇判断和原始位置见根目录的 `literature_reference_assessment.md`。

# 未来参考文献

本目录只保留与当前研究有具体方法或场景交集、但暂不进入主算法的文献，主要用于桥梁/铁路结构健康监测、多传感器融合、FMCW 信号完整性和分布式振动监测的旁证。

当前主线仍是毫米波 FMCW 雷达位移、连续 AoA、几何投影、异步加速度融合和结构主相位 Kalman。PINN、神经网络结构求解、结构参数反演和泛化动力学建模文献已清除；它们不是当前位移解算方法的依据。

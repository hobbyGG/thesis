# 未来参考文献

本目录保存与当前研究方向有明确交集、但暂不进入当前主算法主线的文献。它们主要用于后续扩展：结构参数/损伤识别、物理信息建模、铁路结构动力学、多传感器融合、分布式振动监测和雷达信号完整性。

当前算法仍以毫米波 FMCW 雷达位移、连续 AoA、相位处理、异步加速度融合和结构主相位 Kalman 为主；本目录文献不能直接视为当前方法的实现依据。
